PATRAI BS 1.2.0
================

A responsive Bootstrap 5.3.8 WordPress theme for Super Plast Company.

CONTENT MANAGEMENT
------------------

Appearance > PATRAI BS Options
- Company name, tagline and "Since" label
- Phone, email, WhatsApp and address
- Social URLs and brochure URL
- Homepage fallback copy
- Light blue theme palette

Home Slides
- Add, edit, order or remove responsive homepage slides
- Use a 1920 x 900 px Featured Image
- Edit small heading, button label and button URL in Slide Action

Products
- Separate product manager with title, content, excerpt and Featured Image
- Organize items with Product Categories
- Drag-style ordering can be controlled with the Order field
- Edit short tagline, key features and applications in Product Highlights
- Edit source technical tables in Technical Details & Specifications
- Select, replace and reorder multiple Product Gallery images
- Any newly added product automatically appears in its selected product family

Case Studies
- Separate case-study manager with content and Featured Image
- Organize entries with Industries

Journey
- Add timeline milestones
- Use Timeline Label for a year or period
- Use the Order field to control timeline sequence

Why Choose Us
- Manage homepage feature tiles separately
- Edit title, hover description, line icon, card link and Featured Image
- Use the Order field to control the 2 x 2 grid sequence

Pages
- Edit About Us, Our Journey, Our Products, Case Studies and Contact Us intro copy using the normal WordPress page editor

GLOBAL BRANDING
---------------

Use Appearance > Customize > Site Identity to replace the logo. The included company brochure can be downloaded from the header and footer; upload a replacement PDF and update its URL in PATRAI BS Options when needed.

PERFORMANCE
-----------

- Bootstrap CSS and JavaScript are bundled locally
- No jQuery, page builder or premium slider dependency
- Responsive image srcset, intrinsic dimensions and lazy loading
- First slide is prioritized for faster Largest Contentful Paint
- System font stack avoids external font requests

RECOMMENDED IMAGE SIZES
-----------------------

- Slides: 1920 x 900 px
- Product and case-study cards: 1200 x 830 px or larger
- Inner page banners: 1920 x 700 px
- Logo: transparent PNG or SVG, approximately 300 x 150 px
